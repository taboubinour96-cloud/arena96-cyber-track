# مختبر الكشف — محرّك Sigma حقيقي (بدل الهياكل الفارغة)

## لماذا وُجد هذا المجلد

الأدوات الثماني في `skills_library/cyberskills_96/clis/` كانت **هياكل فارغة**:

```bash
$ python skills_library/cyberskills_96/clis/sigma_lint_cli.py /tmp/bad_rule.yml
{"cli": "sigma_lint_cli.py", "status": "ready", "args": ["/tmp/bad_rule.yml"]}
```

قاعدة YAML فيها `title` فقط — بلا `detection`، بلا `logsource` — تمرّ بلا شكوى.
ولا توجد **قاعدة Sigma واحدة** في المستودع، مع أن `sigma-detection-engineer` مهارة معتمدة.

هذا المجلد يفعل الشيء الذي كان مُدّعى: محرّك يُقيّم قواعد فعلياً على أحداث.

## النتائج الأربع (كلها قابلة لإعادة التشغيل)

| المقياس | النتيجة | ما يعنيه |
|---|---|---|
| **دقة على 200 حدث موسوم يدوياً** | **Precision 100% · Recall 100% · FPR 0%** | قواعدي تعمل على بياناتي |

## العيوب الثلاثة التي كشفها الاختبار (وأُصلحت)

هذه أهم من النتائج، لأن كل واحد منها كان **خطأً حقيقياً في كودي**:

1. **معدّل `|all` كان مُهمَلاً** — القاعدة التي تشترط `-enc` و`-nop` و`hidden` معاً كانت تُطابق عند أول شرط فقط. كشفه `eval_detection` كإيجاب كاذب واحد.
2. **قاعدة PowerShell كانت تُتجاوز** بـ`-EncodedCommand` و`-NoProfile` — صورتان من 6. أُصلحت بـregex يغطي المرادفات.
3. **قاعدة DNS كانت تُطلق على `aaaa…aaaa`** — نطاق آلي مشروع. أُضيف فلتر للمحرف المكرّر.

## خطأان في **القياس** لم يكونا في المحرّك (الأخطر أن يُنشر أحدهما)

1. باني حدثي بنى **حدثاً واحداً** لقاعدة تشترط `all of selection_*` (ثلاث كتل) ⇒ أعلن "28.1% فشل" وهو **كاذب**.
2. قياس "التنفيذ بلا رفض 100%" كان **مضلّلاً** — قاعدة تُرجع `False` دائماً تبدو ناجحة.

> القاعدة المستفادة: النجاح في **التنفيذ** لا يعني صحة **القرار**. المقياس الذي يستحق النشر هو 96.9% لا 100%.

## حدود معلنة (لا مخفية)

| الحدّ | الأثر |
|---|---|
| لا `aggregation` (`by` / `near` / `count`) | كشف التخمين الحقيقي غير ممكن — يُرفض بوضوح لا يُتجاهل |
| لا correlation rules | لا نوافذ متعددة الأحداث |
| لا pipelines خاصة بكل SIEM | لا تحويل تلقائي لـSplunk/Elastic |
| 33 قاعدة من 300 فيها `regex` فقط | تُتخطّى في قياس المطابقة بصراحة |
| 3.1% قصور متبقٍ | سببه باني الحدث (تسلسل قيم متعارضة) لا المحرّك |

**هذا محرّك تعليمي/تحقّقي، لا بديل عن Sigma CLI الرسمي.** قيمته أنه يثبت الفهم، لا أنه أداة إنتاج.

## إعادة التشغيل

```bash
pip install pyyaml requests
cd detection
python eval_detection.py      # بياناتي: 200 حدث
python probe_adversarial.py   # 17 محاولة كسر
python probe_sigmahq.py       # 300 قاعدة مجتمع (يحمّل ~1 MB)
python probe_positive.py      # قياس الدقة الحقيقية
```

*محرّك الكشف هذا يرفع البند 6 من خطة الإغلاق (SIEM حقيقي) من "ملفات Sigma غير مُشغَّلة" إلى "قواعد مُنفَّذة ومقيسة".*
